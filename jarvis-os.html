A natural-language interface where every AI — Claude Code, Antigravity, local models — becomes just another worker. Not a chatbot: an operating environment.

02 Architecture

The frontend speaks to a Python core over WebSockets. An event bus feeds the Agent Manager, which dispatches to whichever engine fits the job.

Electron / Tauri → React → WebSockets → FastAPI → Event Bus → Agent Manager
Claude Code Antigravity OpenAI Gemini Local Ollama MCP Servers Linux APIs
Every AI becomes just another worker. The Brain decides which agent receives each task, instead of tying the whole system to a single model.

04 Core Agents

Each agent does one thing well. The Brain composes them.

🔬 Research

Antigravity Browser · Arxiv · PDFs

“Research reinforcement learning for prop-firm trading.”

  • Finds papers
  • Downloads PDFs
  • Summarizes
  • Builds knowledge graph

⌨️ Code

Claude Code

“Build authentication.” → Plans → Writes → Tests → Commits → Reports. Strong at deep repo understanding and iterative changes.

🌐 Browser

Antigravity

Literally drives Chrome — takes screenshots, verifies UI, clicks buttons, and validates its own work.

🐙 GitHub

Repos · PRs · Issues · Actions

“PR #42 failed because the Docker image is missing Python.” Monitors and explains, automatically.

💻 Terminal

Shell · Docker · Git

Runs docker compose up, git pull, sudo dnf update. Asks permission for dangerous commands.

🧠 Memory

pgvector · Semantic search

“User prefers FastAPI. Current project uses PostgreSQL. Never use Flask.” Long-term memory across sessions.

📈 Finance

MT5 · FundingPips · Binance

Reads accounts and calculates daily PnL, risk, drawdown, and profit targets.

🐧 Linux

Package management

“Jarvis, install OBS.” → Searches → Installs → Configures → Reports success.

05 Agent Communication

The "planner → executor → verifier" pattern: separate reasoning, implementation, and validation.

You: “Build me a weather app.”
Brain → asks Research Agent to find APIs
Research → finds OpenWeather
Code → creates Next.js app
Testing → runs tests
Browser → clicks every button, finds a bug
Code → fixes the bug
GitHub → commits
Brain → reports back to you

06 UI & Voice

Think Iron Man. Agents on the left, conversation in the center, live tasks on the right, terminal at the bottom.

Hey Jarvis → Speech-to-text (Whisper) → Brain → Agents → Text-to-speech (Piper)
“Update all repos.” → Claude codes → GitHub pulls → Docker rebuilds → Browser tests → “Done.”
