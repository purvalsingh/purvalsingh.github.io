02 Architecture

The frontend speaks to a Python core over WebSockets. An event bus feeds the Agent Manager, which dispatches to whichever engine fits the job.

Electron / Tauri → React → WebSockets → FastAPI → Event Bus → Agent Manager
Claude Code Antigravity OpenAI Gemini Local Ollama MCP Servers Linux APIs
Every AI becomes just another worker. The Brain decides which agent receives each task, instead of tying the whole system to a single model.

04 Core Agents

Each agent does one thing well. The Brain composes them.

🔬 Research

Antigravity Browser · Arxiv · PDFs

“Research reinforcement learning for prop-firm trading.”

  • Finds papers
  • Downloads PDFs
  • Summarizes
  • Builds knowledge graph

⌨️ Code

Claude Code

“Build authentication.” → Plans → Writes → Tests → Commits → Reports. Strong at deep repo understanding and iterative changes.

🌐 Browser

Antigravity

Literally drives Chrome — takes screenshots, verifies UI, clicks buttons, and validates its own work.

🐙 GitHub

Repos · PRs · Issues · Actions

“PR #42 failed because the Docker image is missing Python.” Monitors and explains, automatically.

💻 Terminal

Shell · Docker · Git

Runs docker compose up, git pull, sudo dnf update. Asks permission for dangerous commands.

🧠 Memory

pgvector · Semantic search

“User prefers FastAPI. Current project uses PostgreSQL. Never use Flask.” Long-term memory across sessions.

📈 Finance

MT5 · FundingPips · Binance

Reads accounts and calculates daily PnL, risk, drawdown, and profit targets.

🐧 Linux

Package management

“Jarvis, install OBS.” → Searches → Installs → Configures → Reports success.

05 Full Voice Desktop Control

JARVIS doesn't just answer — it acts. Every voice command becomes real work on the desktop: opening apps, moving windows, running commands, filling forms, controlling the mouse and keyboard. Almost anything you can do, it can do.

“Open my trading terminal and pull up EUR/USD.” → Linux Agent launches → Browser Agent navigates
“Clean up my downloads folder.” → Terminal Agent sorts & archives files
“Start a screen recording and open OBS.” → Linux Agent installs/configures/runs
Desktop control runs through OS automation APIs (input, windows, accessibility) with a permission gate — JARVIS asks before anything destructive or irreversible.

06 It Does Things For You

Beyond code — JARVIS handles real-world tasks end to end. It browses, compares, calculates, and prepares the action, confirming with you before committing anything that costs money.

📅 Bookings

“Book a table for two at 8pm.” The Browser Agent finds availability, fills the form, and confirms with you before booking.

🧮 Estimates

“What would a weekend in Goa cost?” The Finance + Research agents gather prices and return an itemized estimate.

✈️ Errands

Flights, hotels, appointments, orders — handled by agents that drive the browser and verify each step.

🛠️ It Builds

“Make me a portfolio tracker.” Claude Code plans, writes, tests, and ships it — then reports back.

07 Remote & Mobile

JARVIS lives on your desktop but answers from anywhere. Send a command from your phone and the desktop agents execute it — with full access to everything above.

📱 Phone → Secure Tunnel / WSS → Brain (Desktop) → Agents → Voice / Push Reply
From the train: “Update all my repos and redeploy.” → Desktop pulls, rebuilds, tests → pushes you “Done.”
From bed: “Give me the estimate for that trip.” → Finance Agent replies to your phone.
The same paired session, authenticated end to end — token-secured, so only your devices can reach your JARVIS.

08 Never Runs Out of Context

You shouldn't have to re-explain yourself. The Memory Agent stores facts, preferences, and project state in a vector database and retrieves only what's relevant — so JARVIS always has the background without burning context.

MEMORY · RECALLED User prefers FastAPI · never Flask Current project → PostgreSQL + pgvector Trades on FundingPips · risk cap 1% Timezone → IST · likes concise replies RETRIEVAL semantic search over pgvector SUMMARY old sessions compressed, not dropped
Relevant memories are injected per request; the rest stays in the store. Context stays small, JARVIS stays informed — no repeating yourself.

09 Agent Communication

The "planner → executor → verifier" pattern: separate reasoning, implementation, and validation.

You: “Build me a weather app.”
Brain → asks Research Agent to find APIs

Code → creates Next.js app
Testing → runs tests
Browser → clicks every button, finds a bug
Code → fixes the bug
GitHub → commits
Brain → reports back to you
